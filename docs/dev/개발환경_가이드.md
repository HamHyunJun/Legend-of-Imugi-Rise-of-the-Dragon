# 개발 환경 가이드 (M0)

M0 단계에서 정한 엔진 버전, 프로젝트 설정, Android 빌드 방법을 정리한다.
기획 근거는 [04 MVP 범위](../design/04_MVP_범위와_구현순서.md), [05 데이터 구조](../design/05_데이터구조.md), [06 모바일 최적화](../design/06_모바일_최적화.md)다.

## 1. 고정 버전

| 항목 | 버전 | 비고 |
|---|---|---|
| Godot | **4.7.2-stable** (표준판, .NET 아님) | 04 문서 규칙: 개발 중 메이저 업그레이드 금지. 4.7.x 패치 업데이트만 허용 |
| JDK | 17 이상 | Android 내보내기 서명에 사용 |
| Android SDK | platform-tools, build-tools 35.0.0 | Gradle 빌드를 켜면 platforms;android-35 와 NDK도 필요 |
| 대상 | arm64-v8a, 가로 모드(센서 가로) | |

## 2. 프로젝트 설정 요약

| 설정 | 값 | 근거 |
|---|---|---|
| 렌더러 | Compatibility (데스크톱·모바일 모두) | 06 문서 2.1. M1에서 Mobile 렌더러와 비교 후 확정 |
| 기준 해상도 | 1280×720, stretch `canvas_items` / `expand` | 18:9~21:9, 4:3 화면비 대응 |
| 3D 렌더 스케일 | 0.75 | 06 문서 2.2 |
| 프레임 | 최대 30fps, 물리 30Hz | 06 문서 1장, 6장 |
| 텍스처 | 2D 기본 필터 Nearest, ETC2/ASTC 임포트 켬, MSAA 끔 | 픽셀 텍스처 스타일 |
| 입력 | 마우스로 터치 흉내 켬 | 데스크톱에서 터치 UI 시험 |

## 3. 폴더 구조와 핵심 스크립트

폴더는 05 문서 2장을 그대로 따른다. 빈 폴더는 `.gitkeep`으로 유지한다.

| 자동 로드 | 파일 | 역할 |
|---|---|---|
| `EventBus` | `scripts/core/event_bus.gd` | 전역 신호. 상태 변경 알림(`flag_changed` 등) |
| `DataRegistry` | `scripts/core/data_registry.gd` | `res://data/` JSON을 시작 시 모두 읽어 보관(읽기 전용) |
| `GameState` | `scripts/core/game_state.gd` | 변하는 값 전부. 세이브 = `to_dict()` |
| `SaveSystem` | `scripts/core/save_system.gd` | `user://saves/` JSON 저장. 임시 파일→이름 변경, `.bak` 복구, 체크섬, 버전 마이그레이션, 백그라운드 전환 시 자동 저장 |

- 자동 로드 순서가 곧 의존 순서다: EventBus → DataRegistry → GameState → SaveSystem.
- 새 JSON 카탈로그는 `data/<폴더>/`에 파일을 넣기만 하면 읽힌다. 내보내기 프리셋의 `include_filter="data/*.json"`이 JSON을 APK에 포함시킨다.
- `docs/`에는 `.gdignore`가 있어 Godot가 임포트하지 않는다.

## 4. 개발용 명령

```bash
# 데이터 검증(실패 시 종료 코드 1)
godot --headless --path . --script res://tools/validate_data.gd

# 세이브 저장/복원 테스트(M0 완료 기준 자동 확인)
godot --headless --path . --script res://tests/test_save_system.gd

# Android 디버그 APK 내보내기
godot --headless --path . --export-debug "Android" builds/android/imugi-debug.apk
```

## 5. 클라우드에서 확인한 것과 CI

- 이 PR 작업 중 리눅스 환경에서 Godot 4.7.2로 임포트, 데이터 검증, 세이브 테스트, **디버그 APK 내보내기와 서명까지 성공**했다(arm64-v8a, 약 28MB).
- `.github/workflows/android-build.yml`이 PR과 main 푸시마다 같은 과정을 돌리고 APK를 아티팩트(`imugi-debug-apk`)로 올린다. GitHub Actions 탭에서 내려받아 기기에 바로 설치할 수 있다.
- 클라우드에서 **할 수 없는 것**: 실제 기기 실행 확인. 이것은 아래 6장대로 사용자 컴퓨터와 기기에서 한다.

## 6. 내 컴퓨터에서 해야 하는 것

### 6.1 처음 한 번 설치

1. **Godot 4.7.2-stable** 표준판 설치(godotengine.org 또는 GitHub 릴리스).
2. 에디터 메뉴 **편집기 → 내보내기 템플릿 관리 → 다운로드 및 설치**(4.7.2용).
3. **JDK 17** 설치(예: `brew install --cask temurin@17`).
4. **Android SDK** 설치. Android Studio를 설치하거나 command-line tools만 받아 다음을 설치한다.
   ```bash
   sdkmanager "platform-tools" "build-tools;35.0.0"
   ```
5. Godot **편집기 설정 → 내보내기 → Android**에서
   - `Java SDK Path`: JDK 17 경로 (macOS 예: `/Library/Java/JavaVirtualMachines/temurin-17.jdk/Contents/Home`)
   - `Android SDK Path`: SDK 경로 (macOS 예: `~/Library/Android/sdk`)
   - 디버그 키스토어는 Godot가 처음 내보낼 때 자동으로 만든다.
6. **Git LFS** 설치: `brew install git-lfs && git lfs install` (바이너리 에셋은 `.gitattributes`에 따라 LFS로 올라간다).

### 6.2 기기에서 M0 완료 기준 확인

1. 기기에서 **개발자 옵션 → USB 디버깅**을 켜고 USB로 연결한다(`adb devices`로 확인).
2. Godot 에디터 오른쪽 위 **원클릭 배포(Android 아이콘)** 를 누르거나, CI 아티팩트 APK를 `adb install -r imugi-debug.apk`로 설치한다.
3. 화면에 회전하는 초록 상자와 정보 문구가 나오면 **빈 씬 실행 확인** 완료.
4. "플래그 켜기/끄기"를 눌러 테스트 플래그를 켠다.
5. 앱을 최근 앱 목록에서 **완전히 종료**하고 다시 실행한다.
6. **부팅 횟수가 1 늘어 있고 테스트 플래그가 켜진 채로** 나오면 저장/복원 확인 완료.
7. 확인할 때 화면 정보(렌더러, GPU 이름, FPS)도 함께 기록해 두면 M1 성능 비교에 쓸 수 있다.

### 6.3 릴리스 서명(M10에서 필요, 지금은 하지 않아도 됨)

```bash
keytool -genkeypair -v -keystore imugi-release.keystore -alias imugi \
  -keyalg RSA -keysize 2048 -validity 10000
```

- 키스토어 파일과 비밀번호는 **절대 레포에 올리지 않는다**(`.gitignore`에 `*.keystore` 등록됨). 잃어버리면 Play 스토어 앱을 업데이트할 수 없으니 따로 백업한다.
- 내보내기 프리셋에 직접 적지 말고 환경 변수로 넘긴다.
  `GODOT_ANDROID_KEYSTORE_RELEASE_PATH`, `GODOT_ANDROID_KEYSTORE_RELEASE_USER`, `GODOT_ANDROID_KEYSTORE_RELEASE_PASSWORD`
- Play 스토어용 **AAB**는 Gradle 빌드가 필요하다(아래 7장).

## 7. 알려진 차이와 나중에 정할 것

- **최소 Android 버전**: 기획은 Android 8.0(API 26)이지만, 지금처럼 Gradle 빌드를 끈 상태에서는 Godot 기본 템플릿 값(API 24)으로 나간다. 24는 26보다 낮아서 기획 대상 기기는 모두 설치된다. API 26으로 올리거나 AAB를 만들려면 **Gradle 빌드**(프로젝트 → Android 빌드 템플릿 설치, 프리셋에서 `Use Gradle Build` 켬)가 필요하며, M10 출시 빌드 때 전환한다.
- **패키지 이름**: `com.hamhyunjun.imugi`. Play 스토어에 한 번 올리면 바꿀 수 없으니 출시 전에 확정한다.
- **앱 아이콘**: `icon.svg`는 임시(태극 + 여의주). M10에서 교체.
