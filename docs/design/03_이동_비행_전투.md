# 03. 이동 · 비행 · 전투 시스템

## 1. 조작 체계 (모바일 기준)

### 1.1 화면 배치

```
┌─────────────────────────────────────────────┐
│ [체력/기운]                    [미니맵] [메뉴] │
│                                             │
│                                             │
│   (화면 왼쪽 절반 아무 곳)     (화면 오른쪽 드래그) │
│    = 가상 조이스틱              = 카메라 회전     │
│                                  [궁극기]     │
│                          [오행기] [음양기]     │
│                     [상호작용]   [공격] [회피/점프] │
└─────────────────────────────────────────────┘
```

- **왼쪽**: 플로팅 가상 조이스틱(터치한 위치에 생성).
- **오른쪽 드래그**: 카메라 회전. 두 손가락 핀치로 줌(3단계 고정 거리 사이를 부드럽게).
- **버튼은 최대 6개로 고정**: 공격, 회피/점프, 오행기, 음양기, 궁극기, 상호작용(상황 버튼). 형태가 바뀌어도 버튼 수와 위치는 같다.
- **상호작용 버튼은 상황형**: 근처 대상에 따라 "대화", "조사", "생장"(덩굴 지점), "분쇄"(바위) 등으로 아이콘이 바뀐다. 지형 능력에 별도 버튼을 만들지 않는다.
- 외부 게임패드(블루투스)는 Godot 입력 맵으로 기본 지원하되 MVP 테스트 대상은 아니다.

### 1.2 이동 모드별 버튼 의미

| 모드 | 회피/점프 버튼 | 공격 버튼 | 비고 |
|---|---|---|---|
| 지상 | 탭: 회피 구르기 / 공중에서 길게: 활공(해금 시) | 기본 공격 | 등반 가능 면에 닿으면 자동 등반 |
| 수중 | 탭: 빠른 헤엄(대시) | 꼬리 치기 | 조이스틱 + 카메라 방향으로 3D 이동 |
| 활공 | 놓으면 활공 종료 | 사용 불가 | 서서히 하강 |
| 비행 | 탭: 공중 회피 / 길게: 급가속(각성 후 고속 비행) | 브레스(자동 조준) | 아래 2장 |

### 2.2 비행 시스템

비행은 "편한 이동 수단"이 아니라 탐험과 전투의 축이 되도록 다음처럼 설계한다.

**조작 방식: 단순화된 아케이드 비행**
- 수영과 같은 방식: 조이스틱을 기울이면 **카메라가 바라보는 방향 기준**으로 날아간다. 고도는 카메라의 위아래 각도로 조절한다(카메라를 위로 올리고 앞으로 밀면 상승).
- 조이스틱을 놓으면 서서히 감속해 제자리 체공한다. 별도의 체공/상승/하강 버튼을 두지 않는다.
- 수영과 비행이 같은 조작 규칙을 공유하므로 이무기 시절 수영으로 익힌 조작이 그대로 비행으로 이어지고, 구현도 하나의 "3D 자유 이동" 컨트롤러로 처리한다.
- 카메라는 비행 시 자동으로 몸 뒤쪽 추적 모드로 바뀐다(오른쪽 드래그로 잠시 둘러보기, 놓으면 복귀).
- 착지: 지면 가까이에서 감속하면 자동 착지. 물 위에서는 입수.
- 이무기 시절의 뱀 몸 애니메이션을 그대로 활용해, 비행은 "하늘을 헤엄치듯" 몸을 물결치며 나아가는 연출로 한다(한국 용의 이미지와 맞고 날개 애니메이션이 필요 없음).

**비행 자원: 기운 게이지(별도 스태미너 없음)**
- 일반 비행은 무제한. 급가속(고속 비행)만 기운 게이지를 소모하고, 일반 비행 중 서서히 회복.
- 자원 관리를 최소화해 모바일 조작 부담을 줄인다.

**비행이 여는 콘텐츠**
- **고공 지역**: 높은 산 정상, 구름섬, 천공 유적. 지역마다 "하늘 층"을 둬서 지상과 다른 보물·사건을 배치.
- **상승 기류**: 특정 지점(폭포 물보라, 화산 열기, 산 능선 바람)에서 높이 올라가는 지형 요소. 높은 곳은 상승 기류를 이어 타야 도달.
- **비행 도전**: 고리 통과 타임어택, 추격(도망치는 신수 따라가기), 낙하물 피하기. 지역당 1~2개, 기록은 로컬 저장.
- **공중 전투**: 아래 3.5 참조.
- **하늘길 이동**: 둥지 위 하늘에서 "하늘길"을 열면 방문했던 지역의 하늘로 이동(빠른 이동). 지역 간 이동은 이 방식으로 하고, 지역 사이를 심리스로 날아가지 않는다.

**비행 범위 제한 (성능과 설계 모두를 위해)**
- 각 지역 씬에는 비행 가능 높이 상한과 경계가 있다. 경계에 다가가면 구름·안개 벽과 바람으로 부드럽게 되돌려 보낸다.
- 지형 게이트는 하늘에서 우회할 수 없는 곳(동굴 내부, 지하, 수중, 봉인된 실내)에 둔다.

### 2.3 지형 능력 (보주 기반)

| 보주 | 능력 이름 | 대상 오브젝트 | 발동 |
|---|---|---|---|
| 목 | 생장 | 시든 덩굴 지점 | 상호작용 버튼 → 덩굴 다리/벽/발판 생성 |
| 화 | 용화 | 얼음 봉인, 얼어붙은 장치 | 상호작용 → 녹임 |
| 토 | 분쇄 | 금 간 바위, 무너진 갱도 | 상호작용 또는 돌진 |
| 금 | 공명 | 고대 금속 장치 | 상호작용 → 패턴 퍼즐 |
| 수 | 심수 / 냉각 | 깊은 물 영역 / 용암 흐름 지점 | 깊은 물은 자동 허용, 용암 지점은 상호작용 |

- 모든 지형 능력은 지정 오브젝트에만 작동한다(자유 지형 편집 없음). 구현과 레벨 디자인이 단순해진다.
- 해당 속성의 형태를 장착 중이면 강화 효과(범위 확대, 숨겨진 상호작용 지점 표시).

## 3. 전투 시스템

### 3.1 기본 원칙

- **액션 전투, 자동 조준 보조**: 공격 버튼을 누르면 가까운 적을 향해 자동으로 방향을 돌린다. 수동 락온은 적을 탭해서 고정(선택 사항).
- **전투 밀도는 낮게**: 한 번에 활성화되는 적은 최대 6마리(성능과 조작 모두 고려).
- **회피 중심**: 적의 큰 공격은 예고 표시(바닥 원형/직선 표시)가 있고 회피로 피한다. 완벽 회피 시 짧은 슬로 모션 + 기운 게이지 충전.

### 3.2 스킬 구성

| 버튼 | 이름 | 내용 | 충전 방식 |
|---|---|---|---|
| 공격 | 기본 공격 | 3타 연속(이무기: 물기·꼬리치기, 용: 발톱·꼬리·짧은 브레스) | 없음 |
| 오행기 | 속성 스킬 | 장착 형태 속성의 스킬. 양/음 형태가 같은 계열의 변형을 가짐 (예: 목 - 청룡 "치유의 덩굴": 덩굴로 적 묶고 아군 회복 / 독목룡 "가시 덩굴": 묶고 독 피해) | 쿨타임(6~10초) |
| 음양기 | 성향 스킬 | 양 계열 형태: 보호막/회복 계열, 음 계열 형태: 흡수/기습 계열. 이무기 시절에는 현재 성향에 따라 "호신"(양) 또는 "흡혼"(음) | 쿨타임(12~18초) |
| 궁극기 | 형태 고유 | 02 문서 표의 궁극기 | 전투 행동으로 게이지 충전 |
| 회피 | 회피 | 짧은 무적 구르기/돌진 | 연속 2회 후 짧은 쿨 |

- **이무기 단계**에서는 오행기 버튼이 비활성(보주 획득 전)이고, 첫 승천 이후 활성화된다. 버튼이 하나씩 열리며 조작을 자연스럽게 배운다.

### 3.3 양 계열과 음 계열의 전투 차이

| | 양 계열 | 음 계열 |
|---|---|---|
| 핵심 | 오래 버티고 아군(동행 NPC, 소환물)과 함께 싸움 | 짧고 강하게, 적에게서 빼앗아 유지 |
| 회복 | 스킬과 패시브로 꾸준한 회복 | 흡수(피해의 일부 회복), 처치 시 회복 |
| 방어 | 보호막, 피해 감소, 반사 | 회피·은신으로 피격 자체를 줄임 |
| 공격 | 중간 화력 + 제어(밀치기, 묶기) | 높은 순간 화력 + 디버프(독, 저주, 기절) |
| 특수 | 쓰러뜨린 적을 놓아주면 이후 같은 종이 덜 공격적 | 발각 전 기습 시 큰 피해, 적 흡수로 궁극기 충전 가속 |

### 3.4 전투 마무리 선택 (흡수 / 놓아주기)

- "제압 가능" 태그를 가진 적(도적, 흑운에 잠식된 동물, 정령)은 체력이 0이 되면 바로 사라지지 않고 **기절 상태**가 된다.
- 기절한 적 근처에서 상호작용 버튼이 두 개의 선택(흡수 / 놓아주기)으로 바뀐다. 3초 안에 선택하지 않으면 자동으로 사라진다(경험치만).
  - 흡수: 음 +2(상한 적용), 체력 일부 회복, 궁극기 게이지 충전
  - 놓아주기/정화: 양 +2(상한 적용), 이후 해당 지역의 같은 종 적대도 감소, 일정 확률로 보답 아이템
- 이 선택은 빠르고 가벼운 반복 행동이므로 1.4의 반복 상한이 적용된다. 전투 흐름을 끊지 않도록 슬로 모션 없이 진행.

### 3.5 공중 전투

- 비행 중 공격 버튼 = 정면 브레스(자동 조준, 근거리 원뿔). 오행기와 궁극기도 공중용 변형을 사용(같은 스킬 데이터의 "공중 변형" 필드).
- 공중 적: 흑운에 물든 새 떼, 요괴 연, 흑운회 도사의 부적 비행체, 공중 보스(주작 화령 등).
- 공중 보스전은 "보스 주위를 선회하며 약점이 드러날 때 공격"하는 패턴으로, 복잡한 3D 조준 없이 선회 + 회피 + 버튼으로 진행한다.
- 지상 적을 하늘에서 공격하는 "급강하 공격"(각성 후)으로 지상·공중 전투를 연결한다.

### 3.6 능력치 구조

| 능력치 | 출처 |
|---|---|
| 체력, 공격력, 방어력 | 레벨 기반 곡선 × 형태 보정(±15%) + 장신구 |
| 기운(비행 급가속·일부 스킬 자원) | 성장 단계 기반 |
| 치명타, 회복량 등 | 성향 특성(02 문서 1.6) + 장신구 |

- 장신구: 슬롯 2개, 수집형(지역 보물, 보스 보상). 강화 시스템은 두지 않는다.
- 형태별 개별 레벨이나 스킬트리는 두지 않는다. 어떤 형태든 같은 레벨에서 비슷한 강함을 보장해, 형태 변경이 "약해지는 선택"이 되지 않게 한다.

### 3.7 적 구성 원칙

- 지역마다 일반 적 3~4종, 정예 1~2종, 수호신령 보스 1, 지역 상위 보스(엔드게임) 1.
- 적 AI는 상태 머신 3~4개 상태(배회 → 경계 → 추적/공격 → 귀환)로 단순하게. 무리 행동은 "우두머리를 따라감" 수준.
- 음 계열의 은신·기습이 의미 있도록 모든 적에게 **시야 원뿔 + 감지 게이지**를 둔다(단순 거리·각도 판정, 레이캐스트는 감지 직전 1회만).
